SURENDHER R – Portfolio

This repository contains my personal portfolio website, designed as a cinematic interactive experience inspired by real-world aerospace missions. Instead of a traditional scrolling portfolio, the website presents my journey through a launch sequence, taking visitors from the launch pad to orbit while showcasing my projects, skills, and achievements.

The portfolio was built to combine engineering, storytelling, and modern web technologies into a single immersive experience.

Features

* Cinematic scroll-driven launch sequence
* Interactive 3D rocket rendered with Three.js
* Mission-inspired storytelling
* Responsive desktop, tablet, and mobile experience
* Premium glassmorphism interface
* Dynamic lighting and atmospheric effects
* Launch pad, tower, and spacecraft animations
* Rocket engine audio synchronized with launch events
* Adaptive background soundtrack
* Smooth physics-based scrolling
* Optimized rendering pipeline for improved performance
* Contact section with direct links to LinkedIn, GitHub, and email

Performance Optimizations

The website has been extensively optimized while maintaining visual quality.

Optimizations include:

* GPU instancing for repeated geometry
* Reduced draw calls
* Memoized React components
* Adaptive rendering strategy
* Optimized render loop
* Frustum culling
* Efficient resource reuse
* Reduced garbage collection
* Stable frame pacing
* Mobile-specific performance improvements

Design Philosophy

The website is designed around the idea that a portfolio should tell a story rather than simply display information.

Each section represents a stage of a space mission:

* Launch Preparation
* Fueling
* Ignition
* Liftoff
* Atmospheric Ascent
* Stage Separation
* Orbital Flight
* Mission Completion

This structure creates a continuous narrative that guides visitors naturally through my work and experience.
